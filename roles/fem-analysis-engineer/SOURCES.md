# SOURCES.md - Finite Element Analysis Engineer

Standards and method references this role builds on. Summary-not-copy:
the role core encodes public engineering mechanics (direct stiffness
method, Euler buckling, Euler-Bernoulli beam theory, V*Q/I shear flow,
lug practice) as original code and text; no proprietary table or
paragraph is reproduced. See [STANDARDS.md](../../STANDARDS.md) for the
full rule.

| Source | Role use | Gated |
|---|---|---|
| FAR 25 (structural loads/stress basis) | analysis context; the report is an input to the stress sign-off chain, never an approval | false |
| CS-25 (EASA counterpart) | same context for EASA programs | false |
| MMPDS-01 chapter 9 (lug allowables family, 7075-T7351) | allowable VALUES are analysis inputs only (F_tu, F_su, F_bru, F_cy for the worked example); the report flags them for verification against the governing issue | false |
| Blevins, Formulas for Natural Frequency and Mode Shape | Euler-Bernoulli characteristic roots (public tables) | false |
| Roark / classic strength-of-materials texts | thin-channel shear-center formula e = 3b^2/(h+6b), section property integrals | false |

The filled deliverable in `templates/fem-report-template.md` is
generated by `core/fem_analysis_core.py` from real computations on the
reference item (flap actuator support bracket, LH rear spar). All
numbers are computed by the engine; the only external inputs are the
material allowables, which are declared as inputs referenced to MMPDS
chapter 9 and re-verified against the governing issue before any
release use.
