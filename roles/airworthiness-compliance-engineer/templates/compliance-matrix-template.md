# Compliance Matrix Template (ORIGINAL skeleton — Aero Agent Roles)

Draft deliverable for an airworthiness compliance checklist /
certification matrix. Original structure based on public-domain
regulatory process (FAR/CS structure, EASA/FAA guidance). Fill every row;
a row with no MoC or document is an OPEN item, never blank.

## Notes
- Status vocabulary: proposed | open | in-work | evidence-available.
- NEVER mark a row "compliant/found" without evidence — that is the
  authority's finding, not ours.
