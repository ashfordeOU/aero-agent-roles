# PSAC Template (ORIGINAL skeleton — Aero Agent Roles)

Draft deliverable structure for a DO-178C Plan for Software Aspects of
Certification. This is original structure informed by public-domain
process knowledge (FAA AC 20-115D guidance, EASA AMC 20-115C) — NOT
copied from any proprietary template vendor. Fill each section; leave no
section blank.

## 1. Scope
- Software item(s) covered
- Aircraft/system and certification basis (TC/STC context)
- Software level(s) with the system-safety source reference

## 2. Software life cycle
- Life cycle model (waterfall/iterative per project)
- Life cycle data produced at each phase
- Transition criteria between phases

## 3. Software life cycle environment
- Development environment and tools
- Verification environment and tools
- Tool qualification approach (tool qualification level, criteria)

## 4. Software development standards
- Requirements standards reference
- Design standards reference
- Code standards reference (language, subset, metrics)

## 5. Software verification strategy
- Verification methods per requirement (test/analysis/review)
- Requirements-based test coverage targets per level
- Data/control coupling analysis approach
- Independence strategy per level

## 6. Software configuration management
- CM environment and tools
- Change control process
- Archive/retrieval approach
- Configuration index contents

## 7. Software quality assurance
- SQA process and independence
- Audit approach
- Conformity review inputs

## 8. Liaison with airworthiness
- Certification authority communication plan
- Issue paper / deviation handling
- Means of compliance reference

## 9. Glossary and acronyms
